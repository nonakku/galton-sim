Statistics Guide

統計表示の見方

このページでは、ガルトンボードのしくみと、シミュレーターに表示される「分布のズレ」「χ²」「p値」を、初めて見る人にも分かるように説明します。

ガルトンボードとは

ガルトンボードは、上から落とした玉がたくさんのピンに当たりながら左右へ分かれ、最後に下の仕切りへ入っていく装置です。

1個の玉の動きは予測しにくいですが、たくさんの玉を落とすと、中央に多く集まり、端に少なくなる山型の分布が見えてきます。

日常例: 人が分かれ道を何度も選ぶ

人がいくつもの分かれ道で右か左を選びながら進むと、全部右や全部左を選ぶ人は少なく、右と左を半分くらいずつ選ぶ人が多くなります。ガルトンボードの玉も、ピンに当たるたびに似たような分かれ方をします。

このシミュレーターでは、玉の半径、ピン間隔、重力、摩擦などの条件を変えて、分布がどう変わるかを観察できます。

まず結論

分布のズレ

小さいほど、理論どおりの山型に近いです。初心者はまずここを見るだけで大丈夫です。

χ²とp値

詳しく見たい人向けの参考値です。玉が少ない間は判断材料が足りないので「集計中」と出します。

なぜ二項分布を使うの？

ガルトンボードでは、玉がピンに当たるたびに、ざっくり言えば「左に行くか」「右に行くか」を繰り返します。

日常例: コインを何回も投げる

コインを8回投げると、表が0回のこともあれば、4回くらい出ることもあります。全部表や全部裏はめったに起きず、半分くらい表になる結果が多くなります。ガルトンボードの左・右の分かれ方も、この感覚に近いです。

ただし、これは左右に分かれる確率がほぼ同じという理想化を置いた場合の考え方です。実際のシミュレーションでは、摩擦、重力、ピン間隔、初速度などの条件で少し偏りが出ることがあります。

たとえば8回分かれ道があるなら、右へ行った回数は0回から8回まであります。真ん中付近に集まりやすく、端には行きにくい。この形を表すのが二項分布です。

9個の仕切りがある場合

理論上の並びは、おおまかに 1 : 8 : 28 : 56 : 70 : 56 : 28 : 8 : 1 のような山型になります。

正規分布は、この二項分布を玉数や段数が多いときに近似したものです。このシミュレーターでは、ガルトンボードの仕組みにより近い二項分布を理論線として使っています。

分布のズレとは

各仕切りに入った玉の割合と、理論上そこに入るはずの割合を比べています。

日常例: 買い物かごの予定と実際

予定では「野菜を5個、果物を3個、飲み物を2個」買うつもりだったのに、実際は「野菜4個、果物5個、飲み物1個」だったとします。予定と実際の差を全部のカテゴリで見たものが、ここでいうズレの感覚です。

観測された割合 と 理論上の割合 の差を、全仕切りで合計して%表示

表示が 分布のズレ: 8.5% なら、実験結果が理論分布からだいたい8.5%ぶんズレている、という読み方です。

  • 0%に近い: 理論分布に近い
  • 大きい: まだ偏りがある、または条件の影響が出ている

χ²は何を見ている？

χ²は「理論上の個数」と「実際の個数」の差を、仕切りごとに調べて足し合わせた値です。

日常例: クラス別の人数を比べる

予定ではA組30人、B組30人、C組30人のはずなのに、実際はA組35人、B組28人、C組27人だったとします。どの組でどれくらい予定と違ったかを見て、全体としてどれくらいズレたかをまとめるのがχ²のイメージです。

χ² = Σ (実際の個数 - 理論上の個数)² / 理論上の個数

差が大きい仕切りが多いほど、χ²は大きくなります。ただし、χ²だけを単独で見ても直感的ではありません。そこでp値も一緒に表示します。

p値の読み方

p値は「理論分布どおりだと仮定したとき、今くらいズレた結果がどのくらい起こりうるか」を表す参考値です。

日常例: 天気予報と珍しさ

「晴れの日が多い地域」で、1週間ずっと雨だったら少し珍しく感じます。でも梅雨ならそこまで珍しくありません。p値は、今見ている結果が「その前提のもとでどれくらい珍しいか」を見るものです。

大事: p値は「理論が正しい確率」ではありません。
  • p値が大きい: 今のズレは、偶然でも起こりそう
  • p値が小さい: 今のズレは、偶然だけでは起こりにくそう

学習用途では、p値を絶対的な判定として使うより、「玉数が増えると結果の見方がどう変わるか」を観察するのがおすすめです。

なぜ端の仕切りをまとめる？

χ²の計算では、理論上の個数が少なすぎる仕切りがあると、結果が不安定になります。特に端の仕切りは、理論上そもそも玉が少ない場所です。

そのため、このシミュレーターでは期待度数が小さい端の仕切りを隣とまとめてから、χ²とp値を計算しています。

日常例: すいている行列をまとめて見る

お店のレジで、1番レーンに1人、2番レーンに0人しかいないとき、どちらが混んでいるかを細かく比べても判断は不安定です。近いレーンをまとめて「このあたりはすいている」と見た方が、全体の様子を落ち着いて比べられます。

イメージ

端の「ほとんど入らない場所」を細かく見すぎず、近くの仕切りと合わせて安定した比較にします。

玉が少ない間に「集計中」と出る理由

玉が少ないと、たまたま右に寄ったり左に寄ったりします。これは異常ではなく、実験の自然なばらつきです。

日常例: じゃんけんを数回だけ見る

友だちとじゃんけんを3回して、相手が3回ともグーを出したとしても、「この人は必ずグーを出す」とは言い切れません。回数が少ないと、偶然の偏りが大きく見えることがあります。

この状態でp値を出すと、初心者には確定的な判定に見えてしまいます。そこで、玉数が少ない間は p値: 集計中 と表示します。

画面で見る順番

  1. まず 分布のズレ を見る。
  2. 玉数が増えるほど、ズレが小さくなるか観察する。
  3. 詳しく見たいときだけ χ²とp値 を見る。
  4. 水平間隔、垂直間隔、重力などを変えて、分布がどう変わるか比べる。
